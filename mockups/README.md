# Cyvexly Studio Mockups

These are high-fidelity visual-direction mockups for the Cyvexly Studio vision plan. They establish the approved **light arctic cyber-blue / smoked-glass** system; they are not final copy-perfect production screens.

## Final mockups

- `01-home.png` — Homepage and mobile hero inset
- `02-services-pricing.png` — Services and Pricing
- `03-work-case-study.png` — Work index and Case Study
- `04-process-planner.png` — Process and Project Planner

The `*-v1.png` files preserve the first dark-theme explorations for reference. The unversioned PNGs are the approved direction.

## Approved art direction

- pale arctic smoky-gray backgrounds with blue-gray atmospheric gradients;
- translucent frosted-white and smoke-gray glass panels;
- dark midnight-slate display typography and cool graphite body text;
- electric royal-blue actions, cyan edge light, and icy blue highlights;
- fine grids, orbital traces, controlled mist, and layered glass reflections;
- airy, advanced, premium, and readable;
- no gaming, crypto, Matrix, hacker, or neon-overload cues.

## Generation method

The final PNGs were created with the built-in image-generation tool using the `ui-mockup` workflow. Prompts specified the page purpose, required sections, exact featured copy, approved palette/material direction, honest concept-project labels, practical information hierarchy, accessible contrast, and prohibited fabricated proof.

## Final prompt set

All four mockups used this shared visual prompt:

> Create a realistic, shippable website UI for Cyvexly Studio in a light arctic cyber-blue system: pale smoky-gray backgrounds with blue-gray atmospheric gradients; translucent frosted-white and smoke-gray glass panels; realistic blur, layered reflections, crisp pale-blue edges, subtle inner highlights, and floating shadows; dark midnight-slate futuristic geometric headings; cool graphite-gray readable body type; electric royal-blue actions; clean cyan and icy-blue light; tiny emerald status accents; fine grids, orbital traces, and controlled mist. Keep it luminous, airy, advanced, calm, premium, and accessible. Avoid gaming, crypto, Matrix, hacker, or neon-overload styling. Do not fabricate logos, testimonials, metrics, awards, badges, ratings, or client claims. No watermark.

Page-specific prompt overlays:

- **Home:** navigation; outcome-led hero; mobile inset; credibility strip; three Concept Project cards; six services; “not a DIY builder” statement; five-stage process; Signal/Orbit/Nexus price preview; FAQ; final CTA; footer.
- **Services + Pricing:** six service groups; service combinations; selected work; four one-time website packages at $1,800 / $3,500 / $5,800 / $8,500; inclusion comparison; add-ons; Care plans at $99 / $229 / $449 monthly; billing explanation; FAQ; CTA.
- **Work + Case Study:** portfolio filters and six clearly labeled Concept Projects; honesty note; Aurora Spaces case study with Challenge, Intended outcome, Audience, Scope, design system, key decisions, desktop/mobile views, accessibility/performance, and CTA.
- **Process + Project Planner:** five stages with client inputs, Cyvexly deliverables, and approval points; multi-step Planner shown on “04 Website & pages”; selectable site types and pages; “Recommend the sitemap”; save/continue controls; no payment required; two-business-day response note.
