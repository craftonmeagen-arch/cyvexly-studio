`C:/app projects/website-independent-review`, Cyvexly review memory/reports,
Builder runtimes, Builder browsers, credentials, or mutable product source as
the review environment. If Team 2 lifecycle helpers are absent or defective,
repair or establish equivalent helper behavior only inside Team 2's authorized
reviewer-owned environment, prove its boundaries, and continue. An environment
setup problem is review work to advance, not permission for a no-work exit.

practical. Challenge authentication and server-side owner authorization; owner
create/edit/preview/publish/archive/reorder behavior; durable persistence and
recovery; upload and asset safety; public rendering; exact TPT navigation and
handoff disclosure; responsive, keyboard, accessibility, failure, and
placeholder boundaries; and the current Render → Namecheap DNS → Clerk

invent external state.

Every firing completes one substantive reachable pass. If there is no new
accepted commit, advance the latest accepted source, unresolved finding,
review debt, coverage gap, or a repairable reviewer-owned capability problem.
A stale example, ambiguous sentence, or misread stipulation is not a no-work
condition. For a true external authority/credential/capability limit, continue
all other reachable work and publish an actionable finding with evidence,
attempted methods, required action, and closure test.

Publish the report and Team 2 intake before teardown. Then close run-created
browsers, stop only manifest-verified Team 2 Auditor processes, remove the
completed disposable runtime/snapshot and unnecessary temporary captures,
protect shared evidence/tools, record retained exceptions, and report reclaimed
disk/RAM. Never edit product source, accepted snapshots, Builder records,
governing rules, Owner Direction, credentials, shared infrastructure, or
scheduler configuration.
