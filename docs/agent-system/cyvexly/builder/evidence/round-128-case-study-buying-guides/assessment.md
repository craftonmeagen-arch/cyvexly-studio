# Round 128 — Case-study buying guides

- **Observed gap:** Velora and Nexora proved capability and offered an inquiry,
  but neither helped an unfamiliar buyer translate the example into a relevant
  service and honest cost path. Nexora's detailed-brief action also lost its
  custom-application context.
- **Change:** both case studies now close with one reusable decision panel that
  connects the demonstration to the appropriate service, pricing, short
  inquiry, and prefilled Planner. Velora explains when the Commerce starting
  point applies and preserves the possibility of a smaller information-led
  scope. Nexora states that the demo is not a fixed package and names the user,
  workflow, data, integration, security, and migration inputs that shape a
  discovery-led quote.
- **Responsive audible:** the first implementation added a separate guidance
  section before the existing CTA and lengthened the phone path. It was
  replaced with one consolidated closing panel. Secondary scope details remain
  visible from tablet upward and use one native, collapsed phone disclosure.
- **Automated proof:** TypeScript, ESLint (one unchanged historical evidence
  warning), the 52-route webpack build, and the 34-route local buyer suite pass.
  Exact geometry is in `metrics.json`; all actions measure 44–66px and both
  routes have zero horizontal overflow at 1440, 768, 390, and 320 CSS pixels.
- **Visible proof:** the optimized local routes were opened in the Codex in-app
  browser at desktop, tablet, and phone sizes. The final Nexora desktop panel
  and Velora phone panel were inspected; the phone scope disclosure opened
  natively; the contextual Velora Planner action reached a visible
  `E-commerce websites` prefill. Earlier in the same run the corresponding
  Nexora action visibly reached the `Custom web applications` prefill. Browser
  warnings/errors were empty and no inquiry was submitted.
- **Source/review boundary:** this is Builder evidence for the exact Round 128
  product patch. Independent exact-source review remains required before the
  change contributes to Chunk 8 completion.
- **Retention:** keep this compact assessment and metrics through independent
  review. No screenshot files are retained; the IAB screenshots were opened
  inline during the round and the next reviewer must produce independent
  evidence from accepted source.
