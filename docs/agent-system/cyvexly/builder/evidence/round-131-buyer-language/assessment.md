model and the shared site chrome. Home and Services present five buyer needs,
including custom web applications, but every footer still promoted the older
Landing pages category and omitted custom web applications. The same pass

keeps the focused Landing pages detail route available without presenting it
as a competing top-level category, uses the established Home brand promise at
the final decision point, and describes the Planner outcome as a scope
recommendation.
